# 備審專題說明（可直接貼上）

字數約 620 字｜繁體中文

---

本專題以「連鎖零售營運決策支援」為題，建構一套可 Demo 的資訊系統原型，結合需求預測、模型可解釋性與規則型管理建議，回應資管領域強調的 AI／資料驅動決策。實務上，門市補貨與人力配置常依賴經驗，面對促銷、假日與品類差異時，容易發生缺貨、庫存積壓或尖峰人力不足。因此本專題不以追求單一模型分數為唯一目標，而是完整呈現「資料→預測→解釋→建議」的決策支援閉環，讓管理者能同時回答：未來會賣多少、依據是什麼、以及此刻該如何行動。

在資料面，專案採用可重現的合成零售日銷量（四門市、四品類、約兩年日頻資料），以固定隨機種子確保 Demo 穩定，並保留替換真實 POS 資料的介面彈性。方法上，先進行時間序列特徵工程（滯後銷量、滾動統計、日曆與促銷／價格等），再以七日移動平均作為 baseline，並以 RandomForest 作為輕量進階模型；評估採時間切分與 MAE、MAPE，避免未來資訊洩漏，並證明特徵化模型相對基準的增益。系統以 Streamlit 實作互動儀表板：使用者可選擇門市與品類、設定未來 N 日預測，檢視歷史與預測曲線、特徵重要性，以及與預測情境相近的歷史銷售日，最後輸出補貨量與人力配置的文字建議，把演算法結果轉譯成營運可執行語言。

本專題的學習重點在於把機器學習嵌入資訊系統與管理流程：一方面展現資料科學基本功（基準模型、評估紀律、可解釋性），另一方面凸顯決策支援系統的價值——預測只是手段，改善補貨與排班決策才是目的。後續可延伸至真實資料驗證、安全庫存與訂購點最佳化，或與 ERP／班表系統整合，作為研究所階段深入「資料驅動營運」與「人機協作決策」的研究起點。
